# SiteHunt

Ищет компании с устаревшими сайтами (первая версия: стоматологии и автосервисы Красноярска), собирает их контакты
и даёт страницу для обзвона с готовым текстом звонка.

## Как устроено

1. **Сбор** (`python run.py collect`) — запросы «ниша + город (+ район / узкая услуга)» в DuckDuckGo через Chrome,
   по 3 страницы выдачи. Агрегаторы, справочники, карты, соцсети и каталоги отсеиваются (`sh/collect.py`: `SKIP`, `AGGR_TITLE`).
   Верх выдачи занимают те, кто уже вкладывается в сайт, поэтому запросы по районам и узким услугам — там старые сайты.
2. **Проверка** (`python run.py check`) — главная открывается в Chrome как с телефона (390×844):
   https и сертификат, адаптивность (meta viewport, прокрутка вбок), год в подвале, старый jQuery,
   устаревшие теги и вёрстка таблицами, время загрузки, вес, мелкий шрифт, старый движок, некликабельный телефон.
   Каждый признак даёт баллы — итог 0–100 «насколько устарел» (`sh/check.py: score`) — и фразу, которую можно сказать клиенту.
   Скриншот главной — `data/shots/`. Контакты — с главной и страницы «Контакты».
3. **Выгрузка** (`python run.py export`) — `web/data.json` + `web/shots/` для страницы и `export/SiteHunt_база.xlsx`.
   На страницу идут живые сайты с баллом от 15.
4. **Страница обзвона** — `web/index.html`, публикуется как артефакт Claude (без домена). Итоги звонков
   (статус, заметка, дата следующего звонка) хранятся в базе артефакта, коллекция `calls/<домен>`.

`python run.py stats` — сколько найдено, проверено, устаревших, с телефоном.

## Настройки — `sh/config.py`
`CITIES`, `DISTRICTS`, `NICHES` (base × районы + extra), `PAGES`, `ENGINES` (Bing выключен: роботу отдаёт пустую выдачу),
`CHECK_TABS` (2 — у компьютера мало свободной памяти).

## Ограничения
- Массовая рекламная рассылка без согласия запрещена (38-ФЗ, ст. 18). Работаем звонками и штучными письмами
  с разбором конкретного сайта.
- Балл ловит технические признаки; «некрасивый, но технически нормальный» сайт виден только на скриншоте.
