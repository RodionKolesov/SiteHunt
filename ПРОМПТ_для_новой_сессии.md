Продолжаем проект SiteHunt — поиск компаний с устаревшими сайтами, чтобы предлагать им новый сайт (я звоню сам).

Проект: C:\Users\bb_ll\Desktop\sitehunt (Python + Playwright/Chrome + SQLite). Сначала прочитай README.md там.
Команды: `python run.py collect` (сбор из поиска) → `python run.py check` (проверка сайтов) → `python run.py export` (выгрузка) → `python run.py stats`.
- sh/config.py — город (Красноярск), 16 районов, ниши (Стоматология, Автосервис) и запросы; ENGINES = только DuckDuckGo (Bing роботу отдаёт пустую выдачу).
- sh/collect.py — поиск, отсев агрегаторов/справочников/соцсетей (SKIP, AGGR_TITLE).
- sh/check.py — сайт открывается как с телефона (390×844): https и сертификат, адаптивность, год в подвале, старый jQuery, вёрстка таблицами/старые теги, время загрузки, вес, мелкий шрифт, старый движок, некликабельный телефон → балл 0–100 «насколько устарел» и причины фразами для клиента; скриншот в data/shots; контакты с главной и страницы «Контакты».
- sh/export.py — web/data.json + web/shots (живые, балл ≥15) и export/SiteHunt_база.xlsx.
- База: data/sitehunt.db (sites, queries). Лог: data/sitehunt.log.

Страница обзвона — артефакт Claude (домен не покупаем): https://claude.ai/artifact/2oJX3g4LHLGJkDBS1WAddw
Файл web/index.html: одна колонка, вкладки по итогу звонка (Не звонили / Не дозвонился / Перезвонить / Интерес / Клиент / Отказ / Все), строки компаний (балл, название, проблемы, телефон, статус), карточка поверх списка: скриншот с телефона, что не так, контакты с «Копировать», текст звонка/WhatsApp, итог звонка (статус, заметка, дата перезвона). Итоги — в базе артефакта, коллекция calls/<домен>.
Обновить страницу: `python run.py export`, затем опубликовать web/index.html на ТОТ ЖЕ url, передав files: data.json и все shots/*.jpg (≤255 файлов за публикацию).
Мне важно: просто и понятно, без «базы слева».
